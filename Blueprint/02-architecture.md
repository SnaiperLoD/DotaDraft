# Architecture

## Stack

Frontend:
- React
- TypeScript
- Vite

Backend:
- NestJS
- TypeScript

Database:
- SQLite

ORM:
- Prisma

## Folder Structure

/client — Frontend application

/server — Backend application

/database — SQLite database

/shared — Common types and constants

/Blueprint — Project instructions

## Backend Modules

Hero Module
Хранение информации о героях.

Draft Module
Создание и управление драфтами.

Evaluation Module
Анализ состава.

Battle Module
Сравнение двух команд.

Match Module
Хранение профессиональных матчей.

History Module
История пользовательских драфтов.

Import Module
Импорт данных.
