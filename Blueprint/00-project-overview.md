# Project Overview

## Project Name

Dota Draft Analyzer MVP

## Purpose

Создать локальное приложение для анализа Dota 2 драфтов.

Пользователь создает команду через процесс Draft, назначает роли героям и получает анализ характеристик своего состава.

Также пользователь может запустить режим "Схватка", где его команда сравнивается с сохраненными профессиональными командами из базы.

## Main Concept

Основная ценность проекта — анализ качества состава.

Приложение должно оценивать:

- синергию героев;
- игровые стратегии;
- сильные стороны;
- слабые стороны;
- потенциальные контр-угрозы.

## Important

Проект НЕ является:

- симулятором настоящей игры;
- системой точного предсказания побед;
- заменой аналитика.

Оценка драфта является инструментом понимания состава.

## MVP Scope

Первая версия:

- работает локально;
- не требует регистрации;
- не требует Steam API;
- использует локальную базу данных;
- использует ограниченную базу профессиональных матчей.

## Future Possibilities

В будущем возможно добавление:

- облачной версии;
- пользователей;
- рейтингов;
- ML моделей;
- расширенной симуляции матчей.
